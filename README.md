# 📺 LAHM TV Global

Plataforma web de streaming desarrollada con HTML, CSS y JavaScript.

## Características

✅ Televisión en vivo mediante HLS.js

✅ Diseño responsive

✅ Compatible con:

- Windows
- Linux
- macOS
- Android
- iPhone
- Edge
- Chrome
- Firefox
- Safari

✅ Filtros por continente

✅ Búsqueda de canales

✅ Historial local

✅ Progressive Web App (PWA)

✅ Service Worker

✅ GitHub Pages

## Instalación Local

Clonar repositorio:

```bash
git clone https://github.com/luhemi19007/streming.git
```

Entrar al proyecto:

```bash
cd streming
```

Abrir:

```text
index.html
```

o ejecutar mediante:

```bash
python -m http.server
```
